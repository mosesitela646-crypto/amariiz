# AMARIIZ MILK — Frontend Premium

Interface commerciale de présentation et de commande AMARIIZ MILK, construite à partir du travail fourni.

## Technologies
- HTML5, CSS3, JavaScript
- Bootstrap 5.3 et Bootstrap Icons
- Backend PHP/API JSON prévu pour l'intégration

## Pages
- index.html : accueil
- pages/catalogue.html : catalogue filtrable des 8 déclinaisons
- pages/commander.html : préparation d'une commande
- pages/connexion.html et pages/inscription.html : maquettes d'accès
- pages/commandes.html : suivi de démonstration
- pages/admin.html : tableau de bord de démonstration
- pages/a-propos.html : présentation de l'entreprise

## Catalogue
- 250 ml : 2 500 FC
- 500 ml : 5 000 FC
- Parfums : vanille et banane
- Compositions : avec sucre et sans sucre
- Zones présentées : Likasi, Lubumbashi et Kolwezi

## Identité visuelle
Palette bleue inspirée de l'étiquette AMARIIZ MILK, avec accent doré. Les prix sont affichés en FC (franc congolais). Aucun logo UPL n'est intégré.

## Démarrage
Ouvrir `index.html` avec Live Server dans Visual Studio Code. Une connexion Internet est nécessaire pour les polices et les CDN Bootstrap.

## À confirmer avant production
Coordonnées officielles, disponibilité, prix, mentions réglementaires, droits d'utilisation des visuels et connexion du backend.
