# AMARIIZ MILK — Interface premium

Site vitrine et maquette de commande construits à partir du travail pratique AMARIIZ MILK.

## Technologies
HTML5, CSS3, JavaScript, Bootstrap 5.3 et Bootstrap Icons. Le backend PHP/API JSON est prévu et documenté, mais n'est pas encore connecté.

## Pages
- index.html : accueil
- pages/catalogue.html : catalogue filtrable des 8 déclinaisons
- pages/commander.html : formulaire et préparation d'un message WhatsApp
- pages/connexion.html et pages/inscription.html : maquettes d'accès client
- pages/commandes.html : suivi de démonstration
- pages/admin.html : tableau de bord de démonstration
- pages/a-propos.html : présentation

## Données du travail
- Yaourts avec sucre / sans sucre
- Parfums banane / vanille
- Petit format 250 ml : 2 500 FC
- Grand format 500 ml : 5 000 FC
- Zones : Likasi, Lubumbashi et Kolwezi

## Identité visuelle
Palette bleue inspirée de l'étiquette AMARIIZ MILK, accent doré, prix en FC (franc congolais). Aucun logo UPL n'est utilisé.

## Lancement
Ouvrir index.html avec Live Server dans VS Code. Une connexion Internet est requise pour les CDN Bootstrap et les polices.

## Important
Les formulaires et l'espace administrateur sont des maquettes front-end : les données ne sont pas enregistrées côté serveur. Le numéro WhatsApp officiel et les informations opérationnelles doivent être confirmés par l'entreprise avant publication.
